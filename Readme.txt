NOCTRA - Intermediate Level Blog Website

Files:
- index.html: page structure and forms
- style.css: colours, layout and responsive design
- script.js: sample blogs, search, category filters, reading dialog, new blog form and dark mode

How to run:
1. Extract this ZIP file.
2. Open the folder in VS Code.
3. Open index.html using Live Server, or open the file in a browser.

Features:
- Home page with a welcome section
- Blog cards with story thumbnails
- Search blogs by title, summary or author
- Filter blogs by category
- Read a blog in a popup window
- Add a new blog using the form
- Save user-created blogs in localStorage
- Switch between light and dark mode
- Responsive layout for smaller screens

Important:
This is a frontend college project. Blogs created by a user are saved only in the same browser using localStorage. They are not uploaded to a server and cannot be seen on another device. Login, online accounts and payments are not included.

Suggested team division:
- HTML member: page structure, navigation, blog form and reading popup
- CSS member: colours, spacing, cards, layout and responsive design
- JavaScript member: search, category filters, publishing blogs and localStorage
- Presentation member: explain the project, demonstrate the features and explain its limitations

Before presenting:
- Read the code together and make sure every team member understands their part.
- Change the sample blog text or add your own original posts.
- Be ready to explain what HTML, CSS, JavaScript and localStorage do.
